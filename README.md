# Crestview College

Backend-first development for a mobile-first Nigerian secondary-school life simulation game. The backend is the source of truth for game state; AI will only provide validated conversational behavior.

## Current phase

Phase 5: data-driven story engine for the Crestview College backend. The project now includes the first authored episode, `SS1 — Term 1 — Episode 1`, plus the in-memory story engine that validates story data, resolves conditions, applies consequences, and moves the player through the First Day narrative. See [backend setup and run instructions](backend/README.md).

The project does not yet include Godot UI, AI, or Phase 6 systems.
